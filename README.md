# Projetos em Python e Dados

Repositório usado como laboratório de estudos em Python e dados. Os projetos mais completos também estão em repositórios próprios.

## Projetos

| Projeto | Descrição |
| --- | --- |
| [dashboard-clima-streamlit](https://github.com/ypernambuco/dashboard-clima-streamlit) | Dashboard de clima com Streamlit, filtros, KPIs e gráficos |
| [etl-clima-python-sqlite](https://github.com/ypernambuco/etl-clima-python-sqlite) | Pipeline ETL de clima com API pública, pandas, SQLite e métricas simples |
| [etl-vendas-python](https://github.com/ypernambuco/etl-vendas-python) | Pipeline ETL de vendas com Python, pandas, logs e saída em Parquet |
| [python_estudos](./python_estudos) | Exercícios práticos de Python com funções, validação, CSV, cálculos e testes |

## Sobre

Os projetos foram organizados para mostrar minha evolução com Python, ETL, SQL, APIs e visualização de dados, sem tentar criar uma arquitetura maior do que o necessário.
