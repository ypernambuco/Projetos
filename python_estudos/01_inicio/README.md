# 01 - Início

Primeiros exercícios em Python, organizados em ordem de evolução. Os scripts começam com entrada e saída de dados e avançam para funções, validação, listas, dicionários e arquivos CSV.

## Arquivos

| Arquivo | O que demonstra |
| --- | --- |
| `01_ola_github.py` | `print`, `input`, tratamento de texto vazio e função `main` |
| `02_classificacao_idade.py` | condicionais, validação de idade e retorno de categoria |
| `03_maioridade.py` | constantes, cálculo simples e separação em funções |
| `04_cadastro_pessoas_csv.py` | cadastro, CSV, leitura para análise e contagem de adultos |

## Exemplo de execução

```powershell
python 01_inicio/04_cadastro_pessoas_csv.py
```
