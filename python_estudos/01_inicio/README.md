# 01 - Início

Primeiros exercícios em Python.

Os scripts começam com entrada e saída de dados e avançam para funções, validação, listas, dicionários e arquivos CSV.

## Arquivos

| Arquivo | O que demonstra |
| --- | --- |
| `01_ola_github.py` | `print`, `input`, texto vazio e função `main` |
| `02_classificacao_idade.py` | condicionais e validação de idade |
| `03_maioridade.py` | constantes, cálculo simples e funções |
| `04_cadastro_pessoas_csv.py` | cadastro, CSV e contagem de adultos |

## Como Executar

Na pasta `python_estudos`, rode:

```powershell
python 01_inicio/04_cadastro_pessoas_csv.py
```

## O Que Aprendi

- criar scripts simples de terminal;
- validar entradas do usuário;
- separar lógica em funções;
- salvar e ler dados em CSV.

## Limitações

- os exemplos são introdutórios;
- não há tratamento avançado de erros;
- o foco é praticar base de Python.
