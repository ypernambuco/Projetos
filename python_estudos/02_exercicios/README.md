# 02 - Exercícios

Exercícios práticos para resolver pequenos problemas com regras simples.

## Arquivos

| Arquivo | O que demonstra |
| --- | --- |
| `01_controle_estoque.py` | cadastro de produtos, validação de preço e quantidade, subtotal, total e formatação de moeda |

## Como Executar

Na pasta `python_estudos`, rode:

```powershell
python 02_exercicios/01_controle_estoque.py
```

## O Que Aprendi

- usar listas e dicionários;
- validar números digitados pelo usuário;
- calcular subtotais e totais;
- organizar a saída no terminal.

## Limitações

- os dados ficam apenas em memória;
- não há persistência em arquivo;
- é um exercício pequeno de prática.
